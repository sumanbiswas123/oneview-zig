Use OneView For Web Links

Open links from Windows, VS Code, and HTML files directly in OneView.

External links open in a detached window first, and you can attach them back into the main app anytime.

Open from browser links Open from HTML files Works with detached windows

What to do

  1. Click Open Windows Settings.
  2. Select OneView in the app page that opens.
  3. Enable it for web links and HTML file types that still need setup.
Apps > Default apps > OneView
Make OneView your default browser

One more thing: Teams can still force links into Edge even after Windows defaults are set.

In Teams, change the link preference to Default browser so chat and message links also open in OneView.

Teams path

  1. Open Teams.
  2. Go to Profile > Settings > Files and links.
  3. Set Link open preference to Default browser.
